# Vendor Demo & Sandbox Verification Checklist

**Source:** `research.md` §10.2 "Items to validate in vendor demos / sandboxes" (original wording preserved in the *Original item* column), plus the conflicts recorded in research.md §4 and §6.
**Created:** 2026-11-03
**Rule:** These are *facts to verify*, not business decisions. Every result stays **Pending verification** until evidence is attached. A demo statement by a salesperson is not sufficient evidence on its own; prefer sandbox execution with screenshots/exports.

## Evidence standard (applies to every check)
1. Vendor sandbox or demo tenant on the **same edition/version** named in research.md §4 (record version/build).
2. Screen recording or dated screenshots of each step, plus exported report/ledger rows (CSV/PDF) showing the amounts.
3. Link to the official documentation page that describes the behaviour (or written vendor confirmation if undocumented).
4. Name of the person who ran the test and date.

## Standard test data (reuse across vendors so results are comparable)
- Project **P-100**, subproject **P-100-A**, WBS node **A.01 Concrete**, cost code **03-300**, cost type **Material**.
- Original budget on A.01 / 03-300 / Material: **100,000**.
- PO-1 for concrete: 10 units × 9,000 = **90,000**, assigned to A.01 / 03-300.
- Subcontract SC-1 (labour-only formwork): **50,000**, retention 5 %.
